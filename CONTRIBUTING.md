# Contributing

Thanks for helping improve the Bregalda portfolio.

## Before opening a pull request

1. Create a focused branch from `main`.
2. Preserve the canonical brand assets in `public/brand/`; do not redraw or recolor them.
3. Keep the interface language in English.
4. Respect keyboard, touch, reduced-motion, and no-JavaScript behavior.
5. Run the complete local gate:

```bash
npm ci
npm run ci
```

## Pull requests

Explain the problem, the decision you made, and how you validated it. Keep unrelated changes in separate pull requests. Screenshots are useful for visual changes but are not required for content-only updates.

Repository counts and star counts are live facts. If you update them, include the source and date in the pull request description.
